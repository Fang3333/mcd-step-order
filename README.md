# 麦麦精算师 🍔

> 麦当劳程序员创意开发大赛参赛作品

**解决一个真实痛点**：每次点麦当劳，都在「想吃啥」和「多少钱」之间反复纠结——想吃的汉堡、小食、饮品能不能凑成一个套餐？套餐里的小食不是我想吃的，换成我要的要不要加钱？和朋友一起点、想点好几个汉堡，怎么搭配最省？到底是点套餐划算，还是单点划算？要不要办张会员卡？

本工具用「**标签式点餐**」的方式，让你在汉堡/小食/饮品三个标签之间自由切换、点好想吃的东西（**都支持多选和数量**），然后一次性给你 **4 个点餐方案**，并诚实拆解价格。

> 🖥️ **在线体验**：https://mcd-step-order.app.workbuddy.host/ （网页版，手机/电脑浏览器直接打开）

## 它能做什么

```
① 定位门店（收藏门店 / 搜索附近）
        ↓
② 选完门店后选取餐方式（堂食自提 / 得来速 / 麦乐送外卖）
        ↓
③ 标签式选餐：🍔汉堡 ⇄ 🍟小食 ⇄ 🥤饮品（自由切换、可多选、可拉黑）
        ↓
④ 自动生成 4 个方案：
   方案1「严格套餐」——买套餐打包价，多含的东西也标给你
   方案2「精准单点」——舍弃套餐优惠，只点你要的
   方案3「灵活搭配」——缺的用相似品替换，往往更省
   方案4「开卡更省」——随单开麦金卡享卡价，融合“不一定全要”
        ↓
⑤ 每个方案：换品加价 / 相似替换明细 / 美团预估差价 / 买卡回本对比
```

示例（用户选：板烧鸡腿堡 ×2 + 薯条 + 可乐）：

```
方案1 · 严格套餐   ¥51.5
  📦 板烧鸡腿堡四件套 ¥28（覆盖：汉堡+中薯条+可乐）
  ➕ 单点：板烧鸡腿堡 ×1
  🎁 多含（你没点，套餐自带）：饮品「鲜萃咖啡」约¥9.5
  比全单点 ¥81.4 省 ¥29.9

方案2 · 精准单点   ¥81.4
  舍弃套餐优惠，只点你要的（贵 ¥29.9，但内容完全精准）

方案3 · 灵活搭配   ¥48.0
  小食：你要的「薯条」→ 套餐换成「脆薯饼」（相似替代，更省）

方案4 · 开卡更省   ¥47.0
  💳 含麦金卡卡费 ¥19（首月）＋卡价套餐
```

## 快速开始

### 方式一：网页版（推荐，无需懂代码）

双击 `start_web.bat`（Windows），会自动启动本地服务并打开浏览器，点按钮即可操作；或直接访问在线版 https://mcd-step-order.app.workbuddy.host/ 。

### 方式二：命令行版

```bash
python step_order.py            # 交互模式（依次问：定位方式、门店、取餐方式、选餐）
python step_order.py --demo     # 演示模式（自动选择，适合快速体验/截图）
```

> Windows 也可双击 `start.bat` 直接启动命令行版。

### 准备环境与 Token

1. Python 3.8+（本工具**零第三方依赖**，仅用标准库，无需 `pip install`）；
2. 打开 https://open.mcd.cn/mcp 用手机号登录 → 右上角【控制台】→【激活】→ 同意协议 → 复制 MCP Token；
3. 设置环境变量 `MCD_TOKEN`（命令行版）：

**Windows（CMD）**：`set MCD_TOKEN=你的Token`
**Windows（PowerShell）**：`$env:MCD_TOKEN="你的Token"`
**macOS/Linux**：`export MCD_TOKEN=你的Token`

> ⚠️ 请勿把真实 Token 写进代码或提交到仓库。本项目已通过 `.gitignore` 忽略本地 token 文件（`token.txt`）。网页版在本地双击 `start_web.bat` 启动时也会自动读取同目录的 `token.txt`。

## 核心设计

### 套餐匹配算法

麦当劳套餐的真实结构是「轮次(rounds)」：主食轮 + 小食轮 + 饮品轮，每轮有若干可选项（`isDefault=1` 为默认项，`diffPrice` 为换品差价）。

匹配算法把用户选的每一样东西，与套餐的对应轮次做**模糊名称比对**（归一化去空白/括号、支持「汉堡↔堡」变体、剥「单品精选」等后缀），并区分：

- ✅ **套餐自带**：命中的就是默认项；
- 🟡 **可换但加价**：命中的是可选项，需按 `diffPrice` 加钱；
- ❌ **套餐没有**：该品类套餐不含，需另单点。

### 4 方案生成（预算驱动）

- **方案1 严格套餐**：贪心用套餐打包，每个套餐标注「多含了什么+价值」；
- **方案2 精准单点**：舍弃套餐优惠，只点你要的；
- **方案3 灵活搭配**：套餐优先，精确匹配不上时允许**同类相似品替代**（如薯条→脆薯饼），并明确标注「你要的X → 套餐换成Y」；
- **方案4 开卡更省**：随单开麦金卡（约¥19/月）享卡价套餐，融合「不一定全要」的预算取舍逻辑。

### 相似品推荐

按核心关键词（都含「薯」「鸡」「牛」等）自动分组，当某样东西被舍弃或需替换时，推荐同类的相似品及其价格，而不是简单一句「没有」。

### 诚实价格核算

```
方案总价 = Σ(套餐实付) + Σ(单点补足)
全单点   = 清单里每样东西的单价 × 数量 之和
省钱金额 = 全单点 - 方案总价
```

### 美团预估价位 + 差价

美团/外卖平台**没有开放接口**，无法自动实时抓价。因此本工具采用**透明估算**，给每个套餐估一个「美团参考到手价区间」，并标出与官方价的差价：

```
美团预估下限 = 官方价 × 0.85   （到店自取/团购常见折扣，估算）
美团预估上限 = 官方价 + 5 元   （外卖加配送费+包装费，估算）
```

> 估算参数在 `combo_matcher.py` 的 `MEITUAN_MIN_RATIO` / `MEITUAN_MAX_EXTRA` 中，可自行调整。所有美团价格均明确标注「估算」，实际以美团 App 为准。

### 开卡 / 买卡对比

麦当劳的「麦金卡」（约 ¥19/月，含超值四件套、免外送费）和「早餐卡」（约 ¥11.9/月，早餐 6 折起）会让部分套餐更便宜。工具会识别菜单里带「卡专享价」标记的套餐，在方案4中给出「随单开卡」的完整价格（含首月卡费），并统计本店享卡价套餐数量。

> 注：麦当劳 MCP 接口目前不提供「是否已开卡」的查询，方案4按「随单开卡」计算，界面已注明。
